# Portfolio: Design & Automation Tools

日々のデザインワークフローやデータ処理の効率化を目的として開発した、Pythonによる自動化ツールのポートフォリオです。

---

## 📂 プロジェクト一覧

### 1. Realtime_Japanese_sub_v0_2_5v14.py [Anime Japanese Learning Player（個人開発／実用レベルで稼働）]
日本語アニメの映像を入力するだけで、セリフの発音解析から韓国語訳までを自動生成する学習用プレイヤーです。既存の音声認識・音声分離ライブラリを組み合わせ、一連の処理パイプラインとして構築しました。

* **主な機能**:
  * 音声前処理：既存の音源分離ライブラリを用いて背景音・効果音とセリフ音声を分離し、音声認識精度を向上
  * 分離した音声を、既存の音声認識（STT）ライブラリで日本語テキストに自動変換
  * 生成した日本語テキストを、韓国語の発音表記と意味に自動変換するロジックを実装
  *「全文表示モード」と「単語別表示モード」を切り替え可能なUIを実装

### 2. Winner Selection Automation (select_winners.py)
SNSイベントのコメントデータから、当選者を公正かつ自動で選定するツールです。テキストの内容量やメンション数をスコア化し、確率的重み付けによるランダム抽選を行います。

* **主な機能**:
  * CSV／Excel形式の参加者データの読み込みと自動処理
  * 絵文字除去・メンション（@アカウント）抽出によるスコア算出
  * 複数人から繰り返し言及される「疑わしいアカウント」の自動検出・除外
  * 除外リストに基づく参加者フィルタリング
  * スコアに応じた確率重み付けランダム抽選による当選者選定
  * 当選結果のExcel自動出力、およびスコア分布・順位の可視化グラフ生成
  * 分析結果を視覚化した、デザイン済みグラフ画像の自動生成
* **入力データ例**: `5000Fol.xlsx`

### 3. Data to Graph (`Data to Graph_final.py`)
エクセルやCSVデータを読み込んで統計分析を実行し、デザイン性の高いグラフ画像として自動生成するツールです。

* **主な機能**:
  * データの統計分析の自動処理
  * 分析結果を視覚化した、デザイン済みグラフ画像の自動生成
* **入力データ例**: `SNS_데이터_분류완료_수정됨(중요).csv`

### 4. UI Mockup Automation (`Mockupautomation-Final.py`)
UIデザインの画面モックアップを素早く、直감的に作成できるプログラムです。

* **主な機能**:
  * 画像が格納されたフォルダの選択
  * スライダー操作によるリアルタイムなパラメータ調整
  * 「Generate」ボタンによるモックアップ画像の自動生成
  * 「Save」ボタンによる結果の保存

---

### 5. Image Crop Automation (`0619Imagecrop2.1-Final.py`)
デザイナーが日常的に行う単純・反復的な画像編集作業を効率化・自動化するためのスクリプトです。

* **主な機能**:
  * `thumb_origin` フォルダ内の元画像（ロゴなど）の自動読み込み
  * クロップおよびリサイズ処理の自動適用
  * 処理済み画像の `thumb_cropped_resized` フォルダへの自動保存
